# Mini Banking System in C

This is one of my first projects in C, built to practise programming concepts by making something a little more practical than basic number problems.

The program is a simple, menu-driven banking system where users can perform basic account operations through the terminal.

## Features

- Create or initialise an account
- Deposit money
- Withdraw money
- Check the account balance
- Display account details
- Exit through a menu

## Built With

- C Programming Language
- Standard C Library

## How to Run

Make sure you have a C compiler such as GCC installed.

**1. Compile the program**

```bash
gcc Mini_Banking_System.c -o banking
```

**2. Run it on Windows**

```bash
.\banking.exe
```

On Linux or macOS, run:

```bash
./banking
```

Replace `Mini_Banking_System.c` with the actual name of your C source file if it is different.
